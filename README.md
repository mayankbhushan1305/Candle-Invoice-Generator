# 🕯️ Candle Invoice Generator

A web-based invoice generation system built using HTML, CSS, and JavaScript for small candle businesses.

The application allows users to generate professional invoices by entering customer details, selecting candle products from a predefined catalog, specifying quantities, and automatically calculating subtotals and the final bill amount.

## Features

- Customer details input
- Candle product selection
- Quantity-based billing
- Automatic total calculation
- Multi-item invoice generation
- Professional invoice layout
- Print-ready invoice design

## Tech Stack

- HTML5
- CSS3
- JavaScript
